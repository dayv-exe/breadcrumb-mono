-upload media to bucket (unprocessed)
trigger lambda on upload complete
change status from uploading to processing in db metadata
if is overlay get base and merge(send to media_convert)
else if is base overlay and merge(send to media_convert)
else if other layer not ready kill process
else if only one layer, send to processed
  change status of media from processing to processed

-handle merge (aws media_convert)
try merge
send outcome to event bridge

-event bridge
if successful do nothing, processed bucket lambda will handle thumbnail
else set media metadata error to error message, add to queue

-upload to bucket (processed)
if no thumbnails in metadata
trigger thumbnail lambda
create thumbnails and send to thumbnail dir
